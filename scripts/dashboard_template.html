Eval loss: measured on the dev set at each checkpoint. Training loss: average of the logged training losses over the 50 steps before the checkpoint (each logged value covers one 5-step window, so single values are noisy).

Weight change learned by the final adapter, by module type

For each adapted layer the adapter adds ΔW = (α/r)·B·A to the frozen base weight. Each bar is the size of that change (Frobenius norm), combined over all layers of the same type. Large matrices get large totals. Before training B = 0, so ΔW = 0 everywhere.

Average change per weight, by module type

Each total divided by the square root of the number of weights it covers (root-mean-square change per weight), so module types of different sizes compare fairly. Values are ×10⁻⁴.

Both charts computed from checkpoints/adapter_best (step 1400).
